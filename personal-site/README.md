# Osebna stran je preseljena / Personal website moved

The personal website is now independent of the Digital Linguistics Playbook.

- Website: https://damjan-popic.github.io/
- Slovenian: https://damjan-popic.github.io/sl/
- English: https://damjan-popic.github.io/en/
- Source and editing guide: https://github.com/damjan-popic/damjan-popic.github.io

Edit Markdown in `content/sl/` and `content/en/` in the new repository, or use
**Uredi to stran / Edit this page** at the bottom of a published page.

This repository no longer builds or stores a second copy of the personal website.
Only static redirects remain in `docs/damjan/`, preserving the old public links.
The Playbook itself, its homepage and its content remain separate and unchanged.

The previous personal-site sources remain available in Git history at commit
`89dbb1fb6dfe5065d676596209410ce75b49032e`; a source ZIP was also preserved before
the migration. No Playbook source files were removed.
